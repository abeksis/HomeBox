      Where things live

      Addresses

      Network storage

      A library on a NAS must be mounted on this box before apps can use it — a container cannot mount a network share by itself. HomeBox writes a systemd automount instead of an fstab line, so an app never starts against an empty folder and decides its library is gone. Once mounted, set Configuration → Media to it.

      Open ports

      Every port this box listens on and the app behind it. All of these are reachable from your network.

      PortAppContainer

      Getting in from outside

      Anyone who can reach port 8443 and knows the dashboard password can install, stop and remove apps. Keep the dashboard on your own network.

      To reach it from elsewhere, use a VPN — one entrance instead of one per app. Install the VPN module and forward UDP 51820 on your router to this box; nothing else needs opening.

      Making one app public

      If an app really has to be on the internet, give it a hostname and a certificate through the proxy, and put a login in front of anything that controls the box.

      Archives

      These archives are on the disk they protect. They cover a mistake, not a failed drive — copy them to another machine.

      Encryption key

      Archives are encrypted with AES-256-GCM using this key, because they include .env with every generated password. Without the key an archive cannot be opened. Store a copy away from this machine.

      Automatic backups

      A scheduled backup is always a settings backup. A media library is too big to copy on a timer, and a job that never finishes is worse than none.

      Restoring

      Restoring runs from a shell on purpose: it overwrites live configuration while apps are running, and it needs the key you stored elsewhere.

      Dashboard password

      The password for this page. Changing it signs out every other device that is signed in.

      Forgot it? There is no email reset. On the server run sudo rm /opt/homebox/state/auth.json, then homebox bootstrap-token, and set a new one.

      Generated passwords

      Created once by install.sh in .env (mode 600) and never changed afterwards — a key that changes makes stored data unreadable.

      Each value stays hidden until you ask for it, so this page can be shown or shared without leaking them all. From a shell:

      homebox secrets <module>
