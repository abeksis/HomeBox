Every module here pins an exact image version on purpose, so this page never jumps an app to a new release behind your back. What it does catch is the case a pinned version does not protect you from: the publisher rebuilding that same version with patched base layers, which is where security fixes arrive. Moving to a genuinely newer version comes with a HomeBox release — git pull && sudo homebox update <module>.

    App Store contents

    Reaching this box from outside

    HomeBox has no authentication. Anyone who can reach port 8443 can install, stop and remove apps and read every container log. That is fine on a trusted LAN and nowhere else.

    The safe way in is a VPN: one door instead of one per app. Install the VPN module, forward UDP 51820 on your router to this box, and nothing else needs to be exposed.

    Publishing an app properly

    If an app really must be public, put it behind the proxy with a real hostname and a real certificate, and put auth in front of anything that manages the box.

    Backup Center

    These backups sit on the same disk they protect. That survives a mistake, not a dead drive — copy them somewhere else.

    Backup Encryption Key

    Every archive is AES-256-GCM encrypted with this key, because it contains .env — every generated password on this box. An archive without the key is unreadable. Keep a copy somewhere that is not this machine.

    Schedule

    The schedule always takes a config backup. A media pool is too large to copy on a timer, and a nightly job that never finishes is worse than none.

    Restoring

    Restore is deliberately a shell operation, not a button: it overwrites live config while the apps using it are running, and it needs the key you kept elsewhere.

    Your dashboard password

    The password you sign in with. Changing it signs out every other device that is currently signed in — that is the point of changing it.

    Forgotten it? There is no reset by email, because there is no email. On the server: sudo rm /opt/homebox/state/auth.json then homebox bootstrap-token to claim the box again.

    Generated secrets

    Generated once by install.sh into .env (mode 600) and never regenerated: an encryption key that changes turns stored data into bytes nobody can read.

    The values are deliberately not shown here. The dashboard has a login now, so this is no longer about who can reach the page — it is that a screen showing thirty passwords is one screenshot, one shoulder, or one shared tab away from leaking all of them at once. Read the one you need from a shell:

    homebox secrets <module>
