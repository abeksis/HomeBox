מה צריך

  • Debian או Ubuntu, התקנה חדשה או קרובה לכך. הפצות אחרות אולי יעבדו, אבל שלבי ההתקנה נכתבו עבור אלה.
  • x86-64 או ARM64 — מחשב מיני, מחשב נייד ישן, מכונה וירטואלית או VPS.
  • משתמש עם הרשאת sudo, וחיבור לאינטרנט.
  • מקום בדיסק לאפליקציות שאתה מתכנן להריץ. HomeBox עצמה קטנה; ספריות תמונות ומדיה — לא.

מריצים את ההתקנה

פותחים טרמינל על המכונה ומדביקים:

{{install}}

היא מתקינה Docker אם הוא חסר, מורידה את HomeBox אל /opt/homebox, יוצרת סיסמאות ייחודיות למכונה הזאת, ומפעילה את ה-reverse proxy ואת לוח הבקרה. היא מתקינה את הגרסה המשוחררת האחרונה, לא את ענף הפיתוח.

היא מסרבת לרוץ מעל התקנה קיימת במקום לשדרג אותה חלקית. כדי לעדכן שרת שכבר יש עליו HomeBox, משתמשים בלשונית Updates.

מעדיף לקרוא אותו קודם?

הרצה של סקריפט מהאינטרנט עם הרשאות root שווה זהירות. אפשר להוריד אותו, לקרוא, ורק אז להריץ:

curl -fsSL https://get.abeksis.net/install.sh -o hb.sh
less hb.sh
sudo bash hb.sh

תופסים בעלות על השרת

בסוף ההתקנה מודפסות כתובת לוח הבקרה וקוד בעלות חד-פעמי:

HomeBox is up.

  Dashboard   http://192.168.1.50:8443

  CLAIM THIS BOX
  …

פותחים את הכתובת בדפדפן, מדביקים את הקוד ובוחרים סיסמה. הקוד מוכיח שמי שפותח את לוח הבקרה הוא מי שהתקין את השרת, והוא עובד פעם אחת בלבד.

סגרת את הטרמינל לפני שהעתקת? מדפיסים אותו שוב:

homebox bootstrap-token
